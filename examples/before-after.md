# Before / after example (illustrative)

This example shows the shape of what the skill produces. It is not a claim
about any real repo.

## Before — vague README

> My cool tool. It does stuff. Install it somehow. More features coming soon.

A reader learns nothing: no job, no install command, no usage, and a promise
about features that do not exist yet.

## After — skill output shape

> A Python CLI that converts CSV and JSON files into GitHub-Flavoured Markdown
> tables, offline, with no dependencies.
>
> Install: see the project's real install command.
>
> Usage: run the project's real main command on a real input file, and show
> the real output it produces.

The after version names the job, states two verifiable facts, and leaves the
install and usage lines to be filled from the actual repo being documented —
never guessed.
